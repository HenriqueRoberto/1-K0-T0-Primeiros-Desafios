# Project Euler Java Solutions

Este projeto contém soluções em **Java** para três problemas do [Project Euler](https://projecteuler.net/), todas executáveis através de um menu interativo.

---

## Problemas resolvidos

1. **Multiples of 3 or 5**  

2. **Even Fibonacci Numbers**  

3. **Largest Prime Factor**  

---

## Como executar

Basta executar o arquivo `Main.java` e seguir o menu interativo para escolher qual exercício deseja rodar.
